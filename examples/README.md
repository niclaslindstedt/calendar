# Examples

- [`calendar-document.json`](calendar-document.json) — a sample calendar
  document, byte-identical in shape to what the app stores (see
  [`docs/storage.md`](../docs/storage.md)). Drop it as `calendar.json` into a
  connected local folder / Dropbox app folder / Drive folder to seed a
  calendar by hand, or use it as the reference when inspecting your own
  document.
